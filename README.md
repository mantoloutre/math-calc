# math-calc

A mathematical and vector calculator built with **Tauri v2** and **Rust**, powered by a Vanilla HTML, CSS, and JavaScript frontend.

> **Note on v1:** The legacy Java (Swing) version has been archived. Its original source code and releases remain accessible on the [`v1-legacy`](https://github.com/mantoloutre/math-calc/tree/v1-legacy) branch.

## Tech Stack

- **Backend:** Rust (Tauri v2)
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla)

## Prerequisites

Make sure you have installed:
- [Node.js](https://nodejs.org/) (v18+)
- [Rust](https://www.rust-lang.org/) and `cargo`
- System dependencies for Tauri (check the [Tauri prerequisites](https://v2.tauri.app/start/prerequisites/))
