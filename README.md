Projet Math-Toolbox - Java Swing

Une application regroupant divers outils de calcul pour l'algèbre linéaire et la géométrie analytique. Initialement créé pour automatiser des exercices académiques, le projet est ouvert à toute fonctionnalité mathématique utile.

    Géométrie : Calcul de la norme, trouver un point avec un vecteur, et surtout les rotations avec un point pivot et un angle (pas juste autour de l'origine).

    Rapport de similitude (K) : Fonctionne pour les formes normales et aussi spécifiquement pour les triangles.

    Matrices : J'ai fait un système pour entrer les matrices rapidement (format 3x6;6;6;6). Ça gère l'addition, la soustraction, la multiplication et même la division.

    Vecteurs : Produit scalaire (avec les composantes ou avec l'angle/normes).

Détails techniques :

    Tout est codé "from scratch" dans le dossier models (Matrice, Point, Rectangle, Triangle, Vecteur). Je n'ai pas utilisé de librairies externes.

    L'interface utilise Java Swing. J'ai ajouté des tooltips sur certains JTextField pour aider à comprendre quoi entrer.

    Le code est documenté avec Javadoc pour que ce soit facile à suivre.
